# 김푸른 웹 이력서 최종 수정본 v8

## 반영 내용

- 상단 제목을 아래 3줄로 고정
  1. 반갑습니다,
  2. 문제를 직접 해결하며 성장한 기획자
  3. 김푸른입니다.
- 데스크톱에서 가운데 제목 문장이 한 줄로 유지되도록 수정
- 소개 문장의 `확대했습니다.`가 단독 줄바꿈되지 않도록 문장 단위로 고정
- 프로젝트 설명의 `프로젝트입니다.`가 단독 줄바꿈되지 않도록 처리
- 전체 페이지 폭을 넓히고 회사명 영역을 줄여 프로젝트 본문 폭 확대
- 태블릿·모바일에서는 자연스럽게 줄바꿈되도록 별도 반응형 적용
